Usando o Google Fonts

O Google Fonts é um serviço gratuito que oferece uma ampla variedade de fontes para uso em projetos web. Para usar uma fonte do Google Fonts, siga os passos abaixo:

  1. Acesse o site do Google Fonts: https://fonts.google.com/
  2. Escolha a fonte que deseja usar e clique nela para abrir a página da fonte.
  3. Na página da fonte, clique no botão "Select this style" para escolher o estilo da fonte que deseja usar (por exemplo, Regular, Bold, Italic, etc.).
  4. Após selecionar o estilo, clique no ícone de "Use" (ícone de código) para obter o código de incorporação.
  5. Copie o código fornecido e cole-o dentro da tag `` do seu documento HTML.
  6. Depois de adicionar o código de incorporação, você pode usar a fonte em seu CSS especificando o nome da fonte na propriedade `font-family`.
